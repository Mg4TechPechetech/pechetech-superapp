## 2026-05-24 - [Optimize AnimatedBuilder with FadeTransition]\n**Learning:** Rebuilding complex widget trees using AnimatedBuilder combined with Opacity can cause unnecessary CPU usage and frame drops, as the whole subtree is rebuilt every frame.\n**Action:** Use specialized transition widgets like FadeTransition whenever possible. FadeTransition updates opacity at the compositing layer, preventing the inner widget tree from being unnecessarily rebuilt on every animation frame.
