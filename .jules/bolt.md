## 2024-06-02 - Flutter animation performance
**Learning:** Using `AnimatedBuilder` combined with `Opacity` is a common anti-pattern that causes full widget tree rebuilds on every frame, even for simple loading skeletons. Replacing it with specialized transition widgets like `FadeTransition` lets the engine handle opacity without rebuilding the widget tree. Also, `flutter test` or `flutter analyze` might silently modify `pubspec.lock` with dependency changes which should be manually reverted using `git restore --staged pubspec.lock && git checkout pubspec.lock`.
**Action:** Actively scan for `AnimatedBuilder` usage where specialized transition widgets (`FadeTransition`, `ScaleTransition`, `SlideTransition`) would suffice. Always carefully check `git status` for unintended `pubspec.lock` modifications before committing.
